## 1. Общие положения
Настоящая Политика конфиденциальности описывает, как приложение «Бесконечная Змейка» обрабатывает информацию пользователей.
**Главный принцип:** Приложение собирает **минимально необходимый** объём данных, строго для обеспечения работоспособности. Мы **не продаём** и **не передаём** персональные данные пользователей третьим лицам, за исключением рекламных партнёров, прямо указанных в настоящей Политике.

## 2. Текущая версия
### 2.1 Персональные данные
Приложение **не собирает** персональные данные, включая:
- Имя, фамилию, отчество
- Адрес электронной почты, номер телефона
- Геолокацию
- Биометрические данные
- Идентификаторы устройства (IMEI, MAC)

### 2.2 Локальные данные (только на устройстве)
Приложение сохраняет **исключительно локально** (внутреннее хранилище Android):
- **Рекорд игры** — максимальный счёт
- **Настройки** — язык, громкость, сложность, тип управления
- **Сохранение игры** — состояние игрового процесса

Эти данные **никогда не передаются** на внешние серверы и удаляются автоматически при удалении Приложения.

2.3 Аналитический модуль (myTracker)
Приложение использует myTracker SDK (ООО «Маи Трекер») для сбора обезличенной статистики использования. Это помогает нам улучшать игровой опыт и исправлять ошибки.

Какие данные обрабатывает myTracker:

Advertising ID (GAID) – для оценки аудитории и анализа эффективности обновлений

Модель устройства и версия ОС – для адаптации под разные устройства

IP-адрес (обезличенный) – для определения региона

События внутри приложения (завершение игры, открытие экранов, разблокировка скинов, выполнение достижений и квестов) – для понимания поведения пользователей

Важно: myTracker не собирает имя, телефон, email, контакты, SMS, содержимое переписок и другие чувствительные данные. Все данные передаются в обезличенном виде и используются только в агрегированной статистике.

Обработка данных осуществляется в соответствии с Политикой конфиденциальности myTracker (https://tracker.my.com/ru/legal/privacy-policy). Разработчик Приложения не имеет доступа к персональным данным пользователей через myTracker.

## 3. Рекламные модули (VK Ads SDK)
Приложение показывает рекламу через **VK Ads SDK** (ООО «В Контакте», ИНН 7707650905).

### 3.1 Зачем нужен интернет
Для загрузки рекламных баннеров и видеороликов Приложению требуются разрешения `INTERNET` и `ACCESS_NETWORK_STATE`. Эти разрешения используются **только для показа рекламы** — игровая логика работает офлайн.

### 3.2 Какие данные обрабатывает VK Ads SDK
При показе рекламы партнёр (VK) может автоматически собирать:
| Тип данных | Назначение |
|---|---|
| **Advertising ID** (GAID) | Показ релевантной рекламы, ограничение частоты показа |
| **Модель устройства и версия ОС** | Адаптация рекламных форматов |
| **IP-адрес (обезличенный)** | Определение региона показа |
| **Факты показа и клика по рекламе** | Статистика рекламных кампаний |
| **Идентификатор рекламной сессии** | Защита от мошенничества |

**Важно:** VK Ads SDK **не собирает** имя, телефон, email, контакты, SMS, содержимое переписок и другие чувствительные данные.

### 3.3 Передача данных третьим лицам
Данные, собранные VK Ads SDK, обрабатываются в соответствии с [Политикой конфиденциальности VK](https://vk.com/privacy). Разработчик Приложения **не имеет доступа** к персональным данным, собираемым рекламным SDK, и не передаёт их другим третьим лицам.

## 4. Права пользователя
В соответствии с Федеральным законом № 152-ФЗ «О персональных данных» вы имеете право:

### 4.1 Отказ от персонализированной рекламы
- **Настройки Android** → **Конфиденциальность** → **Реклама** → **Отключить персонализацию рекламы**

### 4.2 Сброс Advertising ID
- **Настройки Android** → **Конфиденциальность** → **Реклама** → **Сбросить идентификатор рекламы**

### 4.3 Отзыв согласия и удаление данных
Полный отзыв согласия осуществляется путём **удаления Приложения** с устройства. Все локальные данные удаляются автоматически.

## 5. Дети
Приложение имеет возрастной рейтинг **0+** и подходит для пользователей любого возраста:
- Отсутствует насилие, нецензурная лексика, пугающий контент
- Отсутствуют покупки внутри приложения
- Отсутствует социальное взаимодействие между пользователями

**Реклама показывается в соответствии с возрастными ограничениями рекламных материалов VK.** Возрастная маркировка рекламы соответствует требованиям Федерального закона № 38-ФЗ «О рекламе».

---

## 6. Безопасность
- Все данные передаются по защищённому протоколу **HTTPS/TLS 1.2+**
- Локальные данные защищены изоляцией хранилища Android
- Приложение подписано цифровым сертификатом RSA-2048 (APK Signature Scheme v2)
- VK Ads SDK проходит независимый аудит безопасности
